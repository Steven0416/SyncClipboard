# ClipBridge 0.2 Windows 发布及名称恢复

2026-10-26。发布目标 `v0.2.0-preview.1`，Windows x64 完整便携包。
用户授权修复名称发布、配置登录启动、发布 GitHub，并整理手机测试快捷指令清单。

## 缺陷与修复

此前 Bonjour 注册线程仍存活、UI 报告 registered，但实际 A 记录查询和手机固定名称访问失败。
仅重启独立预览客户端后恢复。旧 IsRunning 检查不能判定名称发布可用。

新增 `DNSServiceQueryRecord` 绑定，显式选择网卡，验证配对名称的 IPv4 与有效 TTL，最长轮询 3 秒。
`MdnsRegistrationSupervisor` 每 30 秒验证，缺失、错误地址或注册线程退出后撤销旧句柄并重新注册。
注册失败时保留重试状态，每个服务循环再尝试；禁用、网卡离线时撤销发布。
网络地址事件要求重新发布，即使网络重连后 IP 相同，也不只依赖地址字符串变化。

HTTP 监听与 Bonjour 句柄生命周期分离，名称恢复不再停止正常的 HTTP 监听。
后台服务每轮捕获运行异常并继续尝试，防止一次异常后永久停止；HTTP 关闭有 5 秒取消期限。
状态信息使用已验证/恢复中/等待重试，不能仅以注册回调曾经成功报告已验证。

## 可复用下载包

`script/Build-ClipBridgeRelease.ps1` 从全新发布目录构建 WinUI x64 和 `ClipBridge.Setup`，自带运行时。
包括 Setup/Start/Pair/DisableStartup 命令、单入口已签名手机快捷指令、完整 README 与第三方许可。
不包含本机用户配置、数据库、运行日志或配对文件；每文件清单及 ZIP SHA256 可校验。

向导选择物理网卡，通过 HTTPS 检查现有中继能力，生成新电脑独立设备 ID/Token，并离线生成配对 QR。
复用中继账号但不改 NAS 设置；拒绝明文公网、URL 内凭据、查询或片段；密码不输出到控制台。
已有配置不覆盖现有身份。新目录的本机配置关闭原内置 5033、历史同步及原版自动更新，启用文字按需中继。
配对 QR/迁移文件仅保存在 `client/pairing-private`；连接迁移文件只含中继连接参数，不复制电脑身份。
手机当前只保存一个目标电脑，更换目标需扫描对应电脑二维码，不承诺多电脑自动择优。

当前电脑保留在原独立预览目录，不覆盖 Downloads 原版、不改原 NAS 5033 容器/账号。
备份后只更新程序文件，校验 SavedAccounts 与 LanFirst 完全保持；仅设置启动隐藏窗口。
移除并备份本项目旧 `ClipBridge Bonjour Discovery.lnk`，停止其准确路径进程，安装单一
`ClipBridge 0.2.lnk` 指向集成客户端；未改动其他程序启动项。Bonjour Windows 服务保持自动启动。
