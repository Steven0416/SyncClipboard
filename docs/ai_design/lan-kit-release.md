# ClipBridge LAN Kit 测试版发布

版本：`v0.1.0-preview.1`，Windows x64。此包是原版 SyncClipboard 的局域网辅助工具，不是包含实验性 NAS 功能的完整客户端。

## 已验证的实际组合

原版 SyncClipboard 3.3.1 + 独立 Bonjour 发布器 + 内置服务器 5033 + 当前账号指向本机 `http://127.0.0.1:5033`。2026-10-21 用户确认 iPhone 上传后 Windows 可粘贴，Windows 复制后 iPhone 下载可粘贴。先前服务器只开启、客户端没有本机同步账号时，上传只写入服务器；配置本机账号并开启上传/下载后完整链路成立。

## 包内容和安装

包包含 self-contained win-x64 发布器、`Setup.cmd`、`Start.cmd`、`ClipBridge.ps1`、中文 `README.txt` 和 MIT LICENSE。没有账号、密码、设备 ID、网卡 GUID 或本机配置；不分发 Apple Bonjour，不包含原版客户端。

新电脑先安装原版客户端及 Apple Bonjour，再完整解压此包，运行 Setup，选物理网卡、唯一 `.local` 名称、原版程序路径。脚本创建当前用户两个登录启动项，并启动组件；不写原客户端配置、不改变 NAS、网络类别或防火墙。原版内置服务器、认证及本机同步账号按 README 手动设置。相同局域网的多台电脑必须使用不同名称。

`Start.cmd` 读取本包 settings.json，启动名称发布器和选定的原版程序。名称发布器本身通过信号量拒绝相同名称的重复实例。目录搬迁后必须重新配置；旧安装启动项指向其他目录时，Setup 拒绝覆盖，按 README 先移除旧安装启动项。

移除方式见包内 README。脚本通过 powershell.exe 启动，只对该次本地脚本执行设置参数，不改变持久执行策略。

## 范围

不是一键自动配置的完整安装器。Bonjour 缺失会阻止启动并明确提示。首次配置、权限/防火墙、iPhone 快捷指令仍需手动完成。只实测文本双向同步；未验证实际 DHCP 换址、整机重启恢复、图片文件或 NAS 自动回退。当前电脑的原版客户端与发布器路径仍沿用此前安装，本次打包不会搬迁它们或改变已有启动项。
